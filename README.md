# MC 客户端 Mod 同步

这里仅提供客户端 Mod 清单、作者官方下载地址、校验信息和同步入口。
Mod 由工具直接从发布者下载，本仓库不重新托管 Mod 二进制文件。

## 已有整合包的玩家

1. 完全关闭 Minecraft 和 HMCL。
2. 在右侧 Releases 下载 `MC-GitHub-Update-Onboarding.zip`。
3. 将包内全部内容解压到原客户端根目录，与 `HMCL-3.12.4.exe` 放在一起。
4. 以后双击“启动联机HMCL.cmd”，同步完成后在 HMCL 中选择原整合包。

不需要 GitHub 账号，不需要安装 Git、Python 或其他同步软件。
直接打开原 HMCL.exe 会跳过此同步。

## 更新行为

- 只同步已发布的正式 Mod：新增、替换、移除以及损坏文件修复。
- 全部下载并校验 SHA256 后才切换；失败可重试，意外中断会恢复。
- 旧文件与原配置保留在客户端 `.mc-github-runtime/txn-*`。
- 账号、世界、地图、截图、按键和画质保留。额外自行安装的 Mod 不自动删除。
- 首次接入仅支持原144Mod客户端；发现不同或额外文件时停止，先联系整合包维护者核对。
- Minecraft 1.21.1、NeoForge 21.1.226、游戏配置和枪包不随此入口升级。
- 维护者手动发布并切换正式版本后才会同步，不跟随本地测试目录实时变化。
- 需要能访问 GitHub 以及 Mod 作者的正式下载站。下载或清单读取失败会停止启动。

本工具使用 Windows PowerShell 和系统 HTTPS 验证；运行前可查看本仓库脚本。
第三方 Mod 及其名称、许可归各自作者所有，下载地址和固定版本见 `manifests/`。
